# 拾词 · 英语词库（网页版）

一个参考「不背单词」学习体验的纯前端应用，零依赖、可离线使用。内置 304 个词条（全部配例句）与 84 道语法题。

## 打开方式

双击 `index.html`，用 Chrome / Edge 打开即可（无需安装、无需联网）。学习数据保存在浏览器本地。

## 功能

| 模块 | 说明 |
| --- | --- |
| 首页 | 掌握度环、连续打卡、**今日计划**（新词 / 复习 / 生词本待巩固 + 一键开始）、最近学习 |
| 学习 | 单词卡片：音标、发音、释义、例句；按「忘记 / 模糊 / 认识 / 熟练」四档评分 |
| 今日计划 | 新词 + 到期复习 + 生词本待巩固 + 语法练习，显示今明两天的复习量与语法待复习数 |
| 复习 | 单词与语法共用艾宾浩斯节点：5 分钟 → 30 分钟 → 12 小时 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天 → 30 天 |
| 错题巩固 | 学习/复习中选「忘记」会在本组随机间隔处重复 3 次，「模糊」重复 2 次，强化记忆 |
| 测试 | 拼写、汉译英、英译汉、选择测试，以及**生词本专项**（只练收藏词，四种题型混合，可切换「只练未掌握 / 全部生词」）；错词自动进入复习 |
| 语法 | 独立「语法专项」专栏：84 题（单选 + 语法填空 + 改错辨析），16 张语法速记卡，按词法 / 动词 / 非谓语 / 句法分类，附解析与艾宾浩斯复习 |
| 记忆曲线 | 统计页展示艾宾浩斯复习节点曲线、未来 7 天待复习量，单词详情显示当前记忆阶段 |
| 词库 | 搜索、按状态筛选、生词本收藏、单词详情与个人笔记 |
| 统计 | 7 天学习柱状图、掌握程度分布、记忆曲线、复习预测、每日新词数量、掌握判定次数、自动朗读开关、清空数据 |
| 外观 | 浅色 / 深色主题，桌面与手机自适应 |

## 学习成功的判定

- 一个词只有在 **拼写测试** 或 **汉译英** 中 **答对指定次数**（默认 3 次，可在设置中改为 2–5 次）后，才算「学习成功 / 已掌握」。
- 只是点「认识 / 熟练」不会计入成功次数，只影响下次复习时间。
- 首页掌握度、统计页「已掌握」、词库「已掌握」筛选均按此规则计算。

## 语法专项

- 题库共 84 题：词法 22 · 动词 22 · 非谓语 14 · 句法 26；含单项选择、语法填空（10 题）与改错辨析（6 题）。
- **语法速记卡**：16 张「口诀 + 规则 + 例句」卡片，先记规则再刷题。
- 可按分类筛选，每组最多 10 题；点选项立即判分，并显示正确答案与解析。
- 采用与单词相同的艾宾浩斯复习节点：答对进入下一节点，答错回到起点；首页「今日复习」按到期时间抽取。
- 答错自动收进「语法错题本」，同一题连续答对 2 次才移出；语法错题与单词错题分开记录。

## 设置

- **每日新词数量**：5 / 10 / 15 / 20 词，或 **不限量（全部学完）**。
- **判定「学习成功」所需拼写 / 汉译英正确次数**：2–5 次。
- **题目音标**：拼写 / 汉译英 / 选择测试中可切换「显示音标 / 隐藏音标」，选择会记住。
- 学习时自动朗读、深色模式、清空数据。
- **导出 / 导入**：把单词与语法记录打包成 JSON 备份，换设备或清缓存后可恢复。
- **PWA**：托管版可“添加到主屏幕”，Service Worker 缓存页面，断网也能打开。

## 快捷键

- `空格`：显示释义
- `1` / `2` / `3` / `4`：忘记 / 模糊 / 认识 / 熟练
- 语法练习中：`1`–`4` 选择 A–D，`Enter` 下一题；语法填空输入后按 `Enter` 提交
- `Enter`：提交拼写答案、进入下一题

## 数据说明

- 学习记录、笔记、收藏保存在 `localStorage`（键名 `shici.vocab.v1`），语法练习记录保存在 `shici.grammar.v1`，仅存在本机浏览器。
- 在「统计 → 备份 / 恢复」可导出或导入 JSON；「清空数据」会同时清除单词与语法记录。
- 发音使用浏览器内置语音合成（Web Speech API），不依赖网络音频；若无声音，请检查系统语音包。
