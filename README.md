# 拾词 · 英语词库（网页版）

一个参考「不背单词」学习体验的纯前端单词应用，零依赖、可离线使用。内置 50 个词条，含音标、词性、中文释义与例句。

## 打开方式

双击 `index.html`，用 Chrome / Edge 打开即可（无需安装、无需联网）。学习数据保存在浏览器本地。

## 功能

| 模块 | 说明 |
| --- | --- |
| 首页 | 掌握度环、连续打卡、今日任务进度、最近学习、待复习数量 |
| 学习 | 单词卡片：音标、发音、释义、例句；按「忘记 / 模糊 / 认识 / 熟练」四档评分 |
| 复习 | 间隔重复算法自动安排下次复习（10 分钟 → 1 天 → 3 天 → 7 天 → 21 天 → 60 天） |
| 测试 | 拼写测试（看释义 + 听发音写单词）与选择测试（中英双向四选一），错词自动进入复习 |
| 词库 | 搜索、按状态筛选、生词本收藏、单词详情与个人笔记 |
| 统计 | 7 天学习柱状图、掌握程度分布、每日新词数量、自动朗读开关、清空数据 |
| 外观 | 浅色 / 深色主题，桌面与手机自适应 |

## 快捷键

- `空格`：显示释义
- `1` / `2` / `3` / `4`：忘记 / 模糊 / 认识 / 熟练
- `Enter`：提交拼写答案、进入下一题

## 数据说明

- 学习记录、笔记、收藏保存在 `localStorage`（键名 `shici.vocab.v1`），仅存在本机浏览器。
- 在「统计 → 清空数据」可重置全部进度。
- 发音使用浏览器内置语音合成（Web Speech API），不依赖网络音频；若无声音，请检查系统语音包。
